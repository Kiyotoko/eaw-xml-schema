# Introduction

This project defines XML schema files that allows you or your IDE to verify your XML mod files.

The documentation first explains why you may want to verify your files and how you can install them. Then we show you an example and explain the limitations of xml schemas. Finally, we list some tools and guides that may be useful.

Please note that alternatives exist like the [AlamoEngine Tools LSP](https://github.com/AlamoEngine-Tools/pg-starwarsgame-lsp).
